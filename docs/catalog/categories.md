# Categories

**Where:** **More → Categories** (or Categories in the side menu on larger screens)

![Categories on mobile](/img/screenshots/categories.png)

Categories help customers filter and find products (e.g. *Earrings*, *Necklaces*, *Sale*).

## Create a category

1. Open **Categories**.  
2. Tap **Add** / create.  
3. Enter a name.  
4. Save.

## Use categories on products

When you create or edit a product, assign one or more categories. Products can belong to multiple categories depending on how you set them up.

## Rename or remove

From the categories list, use the menu on a category to rename or delete. Deleting a category does not delete the products themselves — it only removes that label.

## Tips

- Keep names short for mobile filters.  
- Prefer a small, clear set of categories over dozens of near-duplicates.
