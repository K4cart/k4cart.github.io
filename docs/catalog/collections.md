# Collections

**Where:** **More → Collections**

![Collections on mobile](/img/screenshots/collections.png)

Collections are curated groups of products — for example *New arrivals*, *Wedding edit*, or *Under ₹999*. They are different from categories: think of collections as hand-picked shelves.

## Create a collection

1. Open **Collections**.  
2. Create a collection and give it a name.  
3. Open the collection and add the products you want.  
4. Save.

## Show in navigation

Collections can be set to **appear in the storefront navigation** so shoppers can jump to them from the menu. Turn this on for your main merchandising collections; leave it off for internal or temporary groups.

## Homepage use

Pair collections with [banners](../settings/appearance.md) for seasonal campaigns (banner image + collection of featured products).

## Tips

- Update collections regularly so returning customers see something new.  
- Keep navigation collections limited so the menu stays simple on a phone.
