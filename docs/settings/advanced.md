# Advanced settings

**Where:** **Settings → Advanced**

## Danger zone — delete store

You can permanently **delete this store**. That removes the store and its products and cannot be undone.

Only delete if you are sure. Prefer turning products inactive or closing for the season if you might return.

If you delete by mistake, contact [support@k4cart.com](mailto:support@k4cart.com) promptly — recovery is not guaranteed.
