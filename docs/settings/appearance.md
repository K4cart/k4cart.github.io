# Appearance

**Where:** **Settings → Appearance**

![Appearance on mobile](/img/screenshots/settings-appearance.png)

Control how your brand looks on the public storefront.

## Store logo

- Upload a square icon or wide wordmark.  
- Transparent backgrounds work well.  
- Images are compressed automatically (rough guide: up to 5 MB before upload).  

### Hide store name when logo is shown

Turn this **on** if the logo already contains your brand name, so the header does not show both the logo and the text name.

## Banners

Add one or more homepage **banner** images for a carousel (offers, festivals, new lines). Prefer clear mobile-friendly images with little tiny text.

You can remove banners you no longer need from the same screen.

## Preview

Use **View store** from the dashboard to check the result on your phone.

This is the same area used for go-live step 5 — see [Brand your storefront](../go-live/brand-storefront.md).
