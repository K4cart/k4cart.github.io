# General store settings

**Where:** **Settings** (first item under Settings)

## Store information

1. Open **Settings**.  
2. Edit **Store name** (what customers see).  
3. Optionally update the **Description**.  
4. Save.

![General settings on mobile](/img/screenshots/settings-general.png)

Your **Store ID** is shown as a reference code on this page. You do not need it for day-to-day selling.

To change your web address, use [Domains](./domains.md). To delete the store, see [Advanced](./advanced.md).
